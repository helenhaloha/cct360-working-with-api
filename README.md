# Lab 6: Working with API

## Weather Window

This project retrieves live weather data from the public Open-Meteo API and uses the response to change the content and visual atmosphere of the webpage.

### Technical requirements demonstrated

- `fetch()` requests live data from a public API
- JSON weather data is read in JavaScript
- DOM content updates with temperature, humidity, wind, precipitation, and weather conditions
- Weather codes change the background, icon, precipitation animation, and advice
- City buttons trigger new API requests and interface updates
- Error handling provides a clear message if the API is unavailable

### API

Open-Meteo: https://open-meteo.com/

No API key is required.
